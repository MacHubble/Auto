Sincronizzazione GitHub

Collega il tuo account GitHub tramite un Gist privato per sincronizzare automaticamente i dati tra iPhone e iPad.

1° dispositivo (es. iPhone): inserisci solo il Token GitHub (con permesso gist) e premi Salva e Sincronizza. Verrà generato un Gist ID.
2° dispositivo (es. iPad): inserisci lo stesso Token e incolla il Gist ID per scaricare subito il garage.
